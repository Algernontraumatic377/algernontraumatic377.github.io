## 🛠️ Tips for Keeping Maps Organized

- Name your files clearly, using the topic rather than a date code.
- Keep a folder for active maps and a folder for finished ones.
- Make a copy of an important map before a large round of changes.
- Keep branch labels short — a few words is usually enough.
- Use deeper branches for detail and shallow branches for the big picture.
- Back up your map folder the same way you back up other documents.
- Remove branches you no longer need, so the map stays readable.
